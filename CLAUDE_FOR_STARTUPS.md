### Official Documentation

- **Anthropic SDK**: https://github.com/anthropics/anthropic-sdk-python
- **JavaScript SDK**: https://github.com/anthropics/anthropic-sdk-js

### What We're Currently Using
```
- Claude Models: Sonnet, Opus, Haiku (latest versions)
- Framework: FastAPI (backend) + React 19 (frontend)
- Database: MongoDB Atlas
- Deployment: Google Cloud Run
- Integration: Gemini API, Emergent LLM
```

### Key Projects to Explore
- **Claude Code Remote**: Build in isolated containers
- **MCP (Model Context Protocol)**: Build custom tool integrations
- **Claude API Direct**: Integrate Claude into applications
- **Vision API**: Process and analyze images
